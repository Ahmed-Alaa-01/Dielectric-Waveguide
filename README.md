# Dielectric-Waveguide
This repository contains the electromagnetic simulation of a rectangular dielectric waveguide, including the simulation files, generated results, and supporting images. The project focuses on analyzing the electromagnetic behavior and propagation characteristics of the dielectric waveguide using CST Studio Suite.
